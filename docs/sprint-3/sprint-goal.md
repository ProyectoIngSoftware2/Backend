# Sprint 3 Goal

**Objetivo:** Construir el núcleo del negocio (parte 1) — implementar dos nuevos recursos API con CRUD completo, validaciones y manejo de errores, y conectar cuatro pantallas funcionales al frontend a través del API Gateway.

**Resultado esperado al cierre del sprint:**
- API de usuarios y roles (requisito pendiente de Sprint 2) implementada y probada.
- API de horarios y bloqueos implementada con CRUD completo.
- API de detalle de platillos de reserva implementada con CRUD completo.
- Cuatro pantallas funcionales: login, gestión de usuarios, gestión de horarios/bloqueos, reserva del cliente con platillos.
- Documentación Swagger/OpenAPI corregida en el Gateway.
- CORS configurado para el origen de desarrollo del frontend.
- Evidencia de GitHub: push en días diferentes, PR individual y revisión entre pares.
- Documentación Scrum completa (objetivo, backlog, tablero, burndown, dailies, review, retrospectiva).
- Reportes individuales por integrante.

**Criterio de aceptación principal:** El sistema permite crear un usuario, gestionar roles, configurar horarios y bloqueos, y reservar una mesa con platillos asociados, todo a través del Gateway con autenticación JWT y autorización por rol.
