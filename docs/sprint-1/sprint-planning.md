## Objetivo del Sprint 1 (confirmado)

Desarrollar e integrar la infraestructura backend inicial de Punto y Sal
mediante tres microservicios (Clientes, Reservas y Catálogo), un API
Gateway, configuración de Docker Compose, conexión con la base de datos,
pruebas y documentación técnica.

El propósito era dejar una base funcional para continuar con el desarrollo
del frontend durante el Sprint 2.

## Alcance técnico (confirmado)

- Microservicio de Clientes.
- Microservicio de Reservas.
- Microservicio de Catálogo.
- API Gateway.
- Docker Compose.
- Integración con la base de datos.
- Comunicación HTTP entre servicios cuando corresponde.
- Pruebas unitarias y de integración.
- Documentación técnica.

El esfuerzo de implementación se concentró completamente en el backend. El
frontend quedó pendiente para el siguiente Sprint.
